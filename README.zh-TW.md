# 👋 蔡承諺 Eric Tsai

[English](README.md) · **繁體中文**

我目前在墨爾本的蒙納許大學攻讀資訊科技碩士。專案主要聚焦於開放資料儀表板與瀏覽器端的電腦視覺應用。我在儀表板上標示資料更新時間與未採計的讀值，方便使用者判斷資料的時效性。

我來自高雄，畢業於義守大學資訊工程學系。曾在台聚管理顧問股份有限公司資訊處實習，運用 YOLO 進行工業安全影像辨識。
